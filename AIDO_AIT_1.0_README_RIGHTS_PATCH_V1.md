## Rights, access and development boundary

The code in this repository is the **Minimal Public MVP** accompanying the
AIDO-AIT 1.0 manuscript. It is publicly visible for scientific inspection,
reproducibility and peer review, but no open-source license is granted at the
current submission stage. See `RIGHTS_AND_ACCESS_NOTICE.md`.

This repository is **not** the complete AIDO-AIT development or product
codebase. Later development branches, advanced audit rules, orchestration,
experience ledgers, unpublished cases and future AIT 2.0 capabilities remain
outside the public repository.

Research collaboration, institutional evaluation, commercial licensing and
technology-transfer enquiries are welcome.
