# Proposed Code Availability wording — submission-stage

A minimal public reference implementation of AIDO-AIT 1.0 is available through
the author's GitHub repository and is provided to support inspection of the
governance lifecycle described in this study. The public repository is not the
complete development codebase and does not include later laboratory branches,
advanced audit rules, unpublished cases or future AIT 2.0 functionality.

The exact historical AIDO-AIT 1.0 MVP v5.8.1 implementation associated with
the recursive release-infrastructure experiment is version-locked by SHA-256
and can be supplied to editors and reviewers through a controlled verification
package. Its preserved regression result is 49 passed.

No open-source license is granted to the Minimal Public MVP at the current
submission stage; this access restriction is disclosed here explicitly.
Repository and release identifiers should be inserted only after the final
public GitHub location has been independently verified.
